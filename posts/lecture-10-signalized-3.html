제10강. 신호교차로 (3) — 지체와 서비스수준

강의 정보 · 교통용량분석 · 제10강 (120분) 교재: 『도로용량분석의 이론과 실제』 · 근거 편람: 『도로용량편람』(2013) 제8장 신호교차로 선행 학습: 제9강. 신호교차로 (2)

제9강에서 용량과 포화도 XXX를 구했습니다. 이제 신호교차로 서비스수준의 실제 기준인 차량당 제어지체를 계산하고 서비스수준을 판정합니다. 이것이 신호교차로 운영분석의 최종 목표입니다.

학습 목표

  1. 제어지체의 세 구성요소(균일·증분·추가지체)를 안다.
  2. 균일지체 d1d_1d1​와 증분지체 d2d_2d2​를 계산한다.
  3. 차량당 제어지체로 서비스수준을 판정한다.

1. 제어지체의 구성

제어지체(control delay): 신호 제어로 차로군이 감속·정지·가속하며 겪는 추가 시간. 차량당 평균 제어지체가 서비스수준의 기준이다.

차량당 평균 제어지체는 세 지체의 합으로 구합니다(식 8-43).

d=d1⋅PF+d2+d3d = d_1 \cdot PF + d_2 + d_3d=d1​⋅PF+d2​+d3​
  • d1d_1d1​ — 균일지체: 차량이 일정 간격으로 도착한다고 볼 때의 지체.
  • d2d_2d2​ — 증분지체: 임의 도착과 과포화(주기 실패)로 생기는 추가 지체.
  • d3d_3d3​ — 추가지체: 분석기간 이전의 초기 대기행렬로 인한 지체.
  • PFPFPF — 연동보정계수: 신호 연동 효과. 균일지체에만 적용.

2. 균일지체 d1d_1d1​

초기 대기차량이 없을 때(Qb=0Q_b = 0Qb​=0), 균일지체는 결정적 모형으로 구합니다(식 8-47).

d1=0.5 C (1−g/C)21−min⁡(1, X) (g/C)d_1 = \frac{0.5\,C\,(1 - g/C)^2}{1 - \min(1,\,X)\,(g/C)}d1​=1−min(1,X)(g/C)0.5C(1−g/C)2​

여기서 CCC는 주기, g/Cg/Cg/C는 녹색시간비, XXX는 포화도입니다. 녹색시간비가 클수록, 포화도가 낮을수록 균일지체가 작아집니다.

3. 증분지체 d2d_2d2​

임의 도착과 과포화의 영향을 나타내는 증분지체는 포화도 XXX가 1에 가까워질수록 급격히 커집니다(식 8-50).

d2=900 T[(X−1)+(X−1)2+4Xc T]d_2 = 900\,T\left[(X - 1) + \sqrt{(X - 1)^2 + \frac{4X}{c\,T}}\right]d2​=900T[(X−1)+(X−1)2+cT4X​​]

여기서 TTT는 분석기간(시간, 보통 첨두 15분이면 T=0.25T = 0.25T=0.25), ccc는 차로군 용량(vph), XXX는 포화도입니다. XXX는 1.0을 넘을 수도 있습니다.

4. 연동보정계수와 추가지체

  • 연동보정계수 PFPFPF — 신호 연동이 잘 맞으면 균일지체가 줄어듭니다. 고정시간 신호에서는 옵셋편의율과 녹색시간비로 〈표 8-17〉에서 구하며, 고립 교차로나 비연동 이동류는 PF=1.0PF = 1.0PF=1.0입니다.
  • 추가지체 d3d_3d3​ — 분석기간 시작 전 남아 있던 초기 대기행렬(QbQ_bQb​)이 있을 때만 발생합니다. 초기 대기행렬이 없으면(계획·설계 분석 포함) d3=0d_3 = 0d3​=0입니다.

5. 예제 — 지체 계산과 서비스수준

문제. 제9강 예제의 차로군을 이어서 분석한다. 포화교통량 S=3,600S = 3{,}600S=3,600 vphg, 교통량 V=800V = 800V=800 vph, 녹색시간 G=40G = 40G=40초, 주기 C=120C = 120C=120초였고, 그 결과 g/C=0.331g/C = 0.331g/C=0.331, 용량 c=1,192c = 1{,}192c=1,192 vph, 포화도 X=0.67X = 0.67X=0.67이었다. 고립 교차로(PF=1.0PF = 1.0PF=1.0), 초기 대기행렬 없음, 분석기간 T=0.25T = 0.25T=0.25시간일 때 차량당 제어지체와 서비스수준은?

균일지체 (식 8-47)

d1=0.5×120×(1−0.331)21−0.67×0.331=60×0.4480.778≈34.5 초d_1 = \frac{0.5 \times 120 \times (1 - 0.331)^2}{1 - 0.67 \times 0.331} = \frac{60 \times 0.448}{0.778} \approx 34.5 \ \text{초}d1​=1−0.67×0.3310.5×120×(1−0.331)2​=0.77860×0.448​≈34.5 초

증분지체 (식 8-50)

d2=900×0.25[(0.67−1)+(0.67−1)2+4×0.671,192×0.25]≈3.0 초d_2 = 900 \times 0.25 \left[(0.67 - 1) + \sqrt{(0.67 - 1)^2 + \frac{4 \times 0.67}{1{,}192 \times 0.25}}\right] \approx 3.0 \ \text{초}d2​=900×0.25[(0.67−1)+(0.67−1)2+1,192×0.254×0.67​​]≈3.0 초

제어지체 (식 8-43) — PF=1.0PF = 1.0PF=1.0, d3=0d_3 = 0d3​=0.

d=d1⋅PF+d2+d3=34.5×1.0+3.0+0≈37.5 초d = d_1 \cdot PF + d_2 + d_3 = 34.5 \times 1.0 + 3.0 + 0 \approx 37.5 \ \text{초}d=d1​⋅PF+d2​+d3​=34.5×1.0+3.0+0≈37.5 초

서비스수준 — 〈표 8-2〉에서 37.5초는 B(≤ 30)를 넘고 C(≤ 50) 이하이므로 서비스수준 C 입니다.

A ≤ 15
B ≤ 30

6. 지체의 종합

지체는 차로군별로 구한 뒤, 상위 단위로 교통량 가중평균하여 종합합니다.

  • 차로군별 제어지체 → 접근로별 제어지체(차로군 교통량으로 가중평균)
  • 접근로별 제어지체 → 교차로 전체 평균 제어지체(접근로 교통량으로 가중평균)

각 단위마다 〈표 8-2〉로 서비스수준을 판정합니다. 앞서 강조했듯 교차로 전체 서비스수준이 좋아도 특정 차로군은 매우 혼잡할 수 있으므로, 차로군별 결과를 함께 보아야 합니다.

7. 요약

  • 차량당 제어지체 d=d1⋅PF+d2+d3d = d_1 \cdot PF + d_2 + d_3d=d1​⋅PF+d2​+d3​이며, 이 값으로 서비스수준을 판정한다.
  • 균일지체 d1=0.5 C (1−g/C)21−min⁡(1,X)(g/C)d_1 = \dfrac{0.5\,C\,(1 - g/C)^2}{1 - \min(1,X)(g/C)}d1​=1−min(1,X)(g/C)0.5C(1−g/C)2​ — 일정 도착 가정.
  • 증분지체 d2=900 T[(X−1)+(X−1)2+4XcT]d_2 = 900\,T\left[(X-1) + \sqrt{(X-1)^2 + \dfrac{4X}{cT}}\right]d2​=900T[(X−1)+(X−1)2+cT4X​​] — 과포화에 민감.
  • 연동보정 PFPFPF는 균일지체에만, 추가지체 d3d_3d3​는 초기 대기행렬이 있을 때만.
  • 지체는 차로군 → 접근로 → 교차로로 교통량 가중평균해 종합한다.
