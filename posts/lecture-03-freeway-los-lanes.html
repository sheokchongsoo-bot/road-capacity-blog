제3강. 고속도로 기본구간 (2) — 서비스수준 판정과 차로수 결정

강의 정보 · 교통용량분석 · 제3강 (120분) 교재: 『도로용량분석의 이론과 실제』 · 근거 편람: 『도로용량편람』(2013) 제2장 고속도로 기본구간 선행 학습: 제2강. 고속도로 기본구간 (1)

제2강에서 주어진 조건의 용량 c=cj×N×fW×fHVc = c_j \times N \times f_W \times f_{HV}c=cj​×N×fW​×fHV​ 를 구하는 법을 배웠습니다. 이번 강의에서는 그 용량을 이용해 서비스수준을 판정하고, 경사가 급한 구간을 다루며, 마지막으로 필요한 차로수를 결정합니다.

학습 목표

  1. 운영 분석으로 교통량 대 용량비를 구해 서비스수준을 판정한다.
  2. 특정 경사구간의 승용차환산계수(〈표 2-4〉)를 적용한다.
  3. 계획·설계 분석으로 목표 서비스수준을 만족하는 차로수를 결정한다.

1. 두 방향의 분석

같은 이론을 목적에 따라 두 방향으로 씁니다.

  • 운영 분석 — 도로·교통 조건이 주어졌을 때, 현재/장래의 서비스수준을 판정.
  • 계획·설계 분석 — 목표 서비스수준과 장래 수요가 주어졌을 때, 차로수를 결정.

두 분석 모두 동질(homogeneous) 구간(교통·도로 조건이 일정한 구간)을 단위로 하며, 연결로 접속부·차로수 변화 지점·특정 경사구간의 시종점을 경계로 나눕니다.

2. 운영 분석 — 서비스수준 판정

고속도로 기본구간의 주효과척도는 밀도이지만, 실무에서는 계산이 쉬운 교통량 대 용량비(V/cV/cV/c)로 판정한 뒤 필요하면 밀도로 환산합니다. 절차는 다음과 같습니다.

  1. 보정계수 fWf_WfW​, fHVf_{HV}fHV​ 산정 (제2강).
  2. 수요 교통량 VVV를 첨두시간 환산 교통량 VpV_pVp​로 환산.
    Vp=VPHFV_p = \frac{V}{\mathrm{PHF}}Vp​=PHFV​
  3. 용량 산출: c=cj×N×fW×fHVc = c_j \times N \times f_W \times f_{HV}c=cj​×N×fW​×fHV​.
  4. 교통량 대 용량비 Vp/cV_p/cVp​/c 산출.
  5. Vp/cV_p/cVp​/c로 〈표 2-1〉에서 서비스수준을 판정(필요 시 밀도를 보간).

〈표 2-1〉의 설계속도 100 km/h 부분만 다시 보면 다음과 같습니다.

LOS 밀도 (pcpkmpl) 교통량 (pcphpl) V/c
A ≤ 6 ≤ 600 ≤ 0.27
B ≤ 10 ≤ 1,000 ≤ 0.45
C ≤ 14 ≤ 1,350 ≤ 0.61
D ≤ 19 ≤ 1,750 ≤ 0.80
E ≤ 28 ≤ 2,200 ≤ 1.00
F > 28 — —

예제 1 — 서비스수준 판정

문제. 제2강 예제와 같은 구간(편도 3차로, 설계속도 100 km/h, 평지, 차로폭 3.25 m, 측방여유폭 1.0 m 한쪽 장애물, 중차량 소형 5%·중형 6%·대형 4%)이다. 이 구간의 첨두시간 교통량이 해당 방향 V=4,000V = 4{,}000V=4,000 vph, 첨두시간계수 PHF=0.92\mathrm{PHF} = 0.92PHF=0.92일 때 서비스수준은?

제2강에서 fW=0.94f_W = 0.94fW​=0.94, fHV=0.935f_{HV} = 0.935fHV​=0.935, 용량 c≈5,800c \approx 5{,}800c≈5,800 vph를 이미 구했습니다.

Vp=VPHF=4,0000.92≈4,348 vphV_p = \frac{V}{\mathrm{PHF}} = \frac{4{,}000}{0.92} \approx 4{,}348 \ \text{vph}Vp​=PHFV​=0.924,000​≈4,348 vph
Vpc=4,3485,800≈0.75\frac{V_p}{c} = \frac{4{,}348}{5{,}800} \approx 0.75cVp​​=5,8004,348​≈0.75

〈표 2-1〉(100 km/h)에서 V/c=0.75V/c = 0.75V/c=0.75는 C(≤ 0.61)와 D(≤ 0.80) 사이이므로 서비스수준 D 입니다. 밀도로 확인하면, D 구간(밀도 14–19, V/c 0.61–0.80)에서 보간하여

d=14+(19−14)×0.75−0.610.80−0.61≈18 pcpkmpld = 14 + (19 - 14)\times\frac{0.75 - 0.61}{0.80 - 0.61} \approx 18 \ \text{pcpkmpl}d=14+(19−14)×0.80−0.610.75−0.61​≈18 pcpkmpl

밀도 약 18 pcpkmpl 역시 D 구간(≤ 19)에 들어 판정이 일치합니다.

3. 특정 경사구간

지금까지는 일반지형(평지·구릉지·산지)을 가정했습니다. 그러나 종단경사가 3% 이상이고 길이가 500 m 이상인 구간은 중차량의 영향이 훨씬 커지므로, 특정 경사구간으로 따로 떼어 분석합니다.

특정 경사구간에서는 중차량을 하나로 묶어 식 2-6으로 보정계수를 구합니다.

fHV=11+PHV(EHV−1)(식 2-6)f_{HV} = \frac{1}{1 + P_{HV}(E_{HV} - 1)} \qquad (\text{식 2-6})fHV​=1+PHV​(EHV​−1)1​(식 2-6)

여기서 승용차환산계수 EHVE_{HV}EHV​는 경사·경사 길이·중차량 구성비에 따라 〈표 2-4〉에서 찾습니다. 아래는 〈표 2-4〉 중 경사 4% 이상 5% 미만 구간의 발췌입니다 (전체 표는 편람 참조).

〈표 2-4〉 발췌 — 경사 < 5% 구간의 EHVE_{HV}EHV​

경사 길이 (km) 구성비 < 5% < 10% < 20% < 30% < 40% ≥ 40%
≤ 0.0–0.5 1.5 1.5 1.5 1.5 1.5 1.5
≤ 0.5–0.8 2.0 2.0 2.0 1.5 1.5 1.5
≤ 0.8–1.0 4.0 3.0 2.5 2.0 2.0 2.0
≤ 1.0–1.5 5.0 4.0 3.0 3.0 2.5 2.0
> 1.5 5.5 4.0 3.5 3.0 3.0 2.5

여러 경사가 이어지는 복합 경사구간은 먼저 평균 경사(높이 ÷ 전체 길이)를 구해 적용합니다. 모든 경사가 4% 이하이거나 총 길이가 1,000 m보다 짧을 때 이 평균 경사법을 쓰며, 더 급한 경우는 편람 부록의 상세법을 따릅니다.

예제 2 — 특정 경사구간의 용량

문제. 편도 2차로(4차로) 고속도로, 설계속도 100 km/h. 경사 4.5%, 길이 1.2 km의 특정 경사구간이며, 차로폭 3.5 m·측방여유폭 1.5 m(기본조건, fW=1.00f_W = 1.00fW​=1.00)이다. 중차량 구성비가 15%일 때 이 구간의 용량은?

〈표 2-4〉 경사 < 5%, 길이 1.0–1.5 km, 구성비 < 20% → EHV=3.0E_{HV} = 3.0EHV​=3.0.

fHV=11+0.15 (3.0−1)=11.30≈0.769f_{HV} = \frac{1}{1 + 0.15\,(3.0 - 1)} = \frac{1}{1.30} \approx 0.769fHV​=1+0.15(3.0−1)1​=1.301​≈0.769
c=cj×N×fW×fHV=2,200×2×1.00×0.769≈3,384 vphc = c_j \times N \times f_W \times f_{HV} = 2{,}200 \times 2 \times 1.00 \times 0.769 \approx 3{,}384 \ \text{vph}c=cj​×N×fW​×fHV​=2,200×2×1.00×0.769≈3,384 vph

같은 15% 중차량이라도 평지(중형 E=1.5E = 1.5E=1.5)라면 fHV=1/[1+0.15(0.5)]≈0.930f_{HV} = 1/[1 + 0.15(0.5)] \approx 0.930fHV​=1/[1+0.15(0.5)]≈0.930, 용량은 약 4,090 vph입니다. 급경사 하나로 용량이 4,090 → 3,380 vph로 급감하는 것을 볼 수 있습니다.

4. 계획·설계 분석 — 차로수 결정

이번에는 반대로, 목표 서비스수준과 장래 교통수요가 주어졌을 때 필요한 차로수를 구합니다.

① 첨두 설계시간 교통량 — 계획교통량(AADT)에 설계시간계수 KKK, 중방향계수 DDD, 첨두시간계수 PHF를 반영합니다.

PDDHV=AADT×K×DPHF(식 2-9)\mathrm{PDDHV} = \frac{\mathrm{AADT} \times K \times D}{\mathrm{PHF}} \qquad (\text{식 2-9})PDDHV=PHFAADT×K×D​(식 2-9)

중방향계수 DDD의 참고값은 〈표 2-5〉와 같습니다.

구분 중방향계수 DDD
도시 지역 0.60 (0.55–0.65)
지방 지역 0.65 (0.60–0.70)

② 차로당 서비스교통량 — 목표 서비스수준 iii의 최대 서비스교통량에 보정계수를 적용합니다.

MSFi=cj×(V/c)i,SFi=MSFi×fW×fHV (차로당)\mathrm{MSF}_i = c_j \times (V/c)_i, \qquad \mathrm{SF}_i = \mathrm{MSF}_i \times f_W \times f_{HV} \ (\text{차로당})MSFi​=cj​×(V/c)i​,SFi​=MSFi​×fW​×fHV​ (차로당)

③ 차로수 — 수요를 차로당 공급으로 나누고 올림합니다.

N=⌈PDDHVSFi⌉N = \left\lceil \frac{\mathrm{PDDHV}}{\mathrm{SF}_i} \right\rceilN=⌈SFi​PDDHV​⌉

예제 3 — 차로수 결정

문제. 도시 지역 고속도로를 서비스수준 D로 계획한다. 계획교통량 AADT=80,000\mathrm{AADT} = 80{,}000AADT=80,000 대/일, K=0.10K = 0.10K=0.10, D=0.60D = 0.60D=0.60, PHF=0.90\mathrm{PHF} = 0.90PHF=0.90. 설계속도 100 km/h, 평지, 기본조건(fW=1.00f_W = 1.00fW​=1.00), 중차량은 중형 10%이다. 편도 몇 차로가 필요한가?

① 첨두 설계시간 교통량

PDDHV=80,000×0.10×0.600.90≈5,333 vph\mathrm{PDDHV} = \frac{80{,}000 \times 0.10 \times 0.60}{0.90} \approx 5{,}333 \ \text{vph}PDDHV=0.9080,000×0.10×0.60​≈5,333 vph

② 차로당 서비스교통량 — 〈표 2-1〉에서 100 km/h·D의 MSFD=1,750\mathrm{MSF}_D = 1{,}750MSFD​=1,750 pcphpl. 중형 10%이므로 fHV=1/[1+0.10(1.5−1)]≈0.952f_{HV} = 1/[1 + 0.10(1.5 - 1)] \approx 0.952fHV​=1/[1+0.10(1.5−1)]≈0.952.

SFD=1,750×1.00×0.952≈1,666 vphpl\mathrm{SF}_D = 1{,}750 \times 1.00 \times 0.952 \approx 1{,}666 \ \text{vphpl}SFD​=1,750×1.00×0.952≈1,666 vphpl

③ 차로수

N=⌈5,3331,666⌉=⌈3.20⌉=4 차로N = \left\lceil \frac{5{,}333}{1{,}666} \right\rceil = \lceil 3.20 \rceil = 4 \ \text{차로}N=⌈1,6665,333​⌉=⌈3.20⌉=4 차로

따라서 서비스수준 D를 만족하려면 편도 4차로가 필요합니다.

5. 요약

  • 운영 분석: Vp=V/PHFV_p = V/\mathrm{PHF}Vp​=V/PHF → c=cjNfWfHVc = c_j N f_W f_{HV}c=cj​NfW​fHV​ → Vp/cV_p/cVp​/c → 〈표 2-1〉로 서비스수준 판정.
  • 특정 경사구간(경사 ≥ 3%, 길이 ≥ 500 m): 〈표 2-4〉로 EHVE_{HV}EHV​를 찾아 식 2-6으로 fHVf_{HV}fHV​ 계산.
  • 계획·설계 분석: PDDHV=AADT K DPHF\mathrm{PDDHV} = \dfrac{\mathrm{AADT}\,K\,D}{\mathrm{PHF}}PDDHV=PHFAADTKD​, 목표 LOS의 SFi\mathrm{SF}_iSFi​로 N=⌈PDDHV/SFi⌉N = \lceil \mathrm{PDDHV}/\mathrm{SF}_i \rceilN=⌈PDDHV/SFi​⌉.

참고 — 미국 HCM(7판)과의 비교

  • HCM은 V/cV/cV/c 보간 대신 속도-교통량 곡선으로 밀도를 직접 계산해 판정하며, 밀도 경계(A ≤ 11 … E ≤ 45 pc/mi/ln)는 자유속도와 무관하게 동일합니다.
  • 수요가 용량을 넘으면 밀도와 무관하게 LOS F로 처리합니다.
  • 차로수 결정은 목표 LOS의 서비스교통량으로 수요를 나누는 같은 골격입니다.
