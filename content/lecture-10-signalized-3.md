> **강의 정보** · 교통용량분석 · 제10강 (120분)
> **교재**: 『도로용량분석의 이론과 실제』 · **근거 편람**: 『도로용량편람』(2013) 제8장 신호교차로
> **선행 학습**: [제9강. 신호교차로 (2)](lecture-09-signalized-2.html)

제9강에서 **용량**과 **포화도** $X$를 구했습니다. 이제 신호교차로 서비스수준의 실제
기준인 **차량당 제어지체**를 계산하고 서비스수준을 판정합니다. 이것이 신호교차로
운영분석의 최종 목표입니다.

## 학습 목표

1. **제어지체**의 세 구성요소(균일·증분·추가지체)를 안다.
2. **균일지체** $d_1$와 **증분지체** $d_2$를 계산한다.
3. 차량당 제어지체로 **서비스수준을 판정**한다.

---

## 1. 제어지체의 구성

> **제어지체(control delay)**: 신호 제어로 차로군이 감속·정지·가속하며 겪는 추가
> 시간. 차량당 평균 제어지체가 서비스수준의 기준이다.

차량당 평균 제어지체는 세 지체의 합으로 구합니다(식 8-43).

$$d = d_1 \cdot PF + d_2 + d_3$$

- $d_1$ — **균일지체**: 차량이 일정 간격으로 도착한다고 볼 때의 지체.
- $d_2$ — **증분지체**: 임의 도착과 과포화(주기 실패)로 생기는 추가 지체.
- $d_3$ — **추가지체**: 분석기간 이전의 초기 대기행렬로 인한 지체.
- $PF$ — **연동보정계수**: 신호 연동 효과. **균일지체에만** 적용.

## 2. 균일지체 $d_1$

초기 대기차량이 없을 때($Q_b = 0$), 균일지체는 결정적 모형으로 구합니다(식 8-47).

$$d_1 = \frac{0.5\,C\,(1 - g/C)^2}{1 - \min(1,\,X)\,(g/C)}$$

여기서 $C$는 주기, $g/C$는 녹색시간비, $X$는 포화도입니다. 녹색시간비가 클수록,
포화도가 낮을수록 균일지체가 작아집니다.

## 3. 증분지체 $d_2$

임의 도착과 과포화의 영향을 나타내는 증분지체는 포화도 $X$가 1에 가까워질수록
급격히 커집니다(식 8-50).

$$d_2 = 900\,T\left[(X - 1) + \sqrt{(X - 1)^2 + \frac{4X}{c\,T}}\right]$$

여기서 $T$는 분석기간(시간, 보통 첨두 15분이면 $T = 0.25$), $c$는 차로군 용량(vph),
$X$는 포화도입니다. $X$는 1.0을 넘을 수도 있습니다.

## 4. 연동보정계수와 추가지체

- **연동보정계수 $PF$** — 신호 연동이 잘 맞으면 균일지체가 줄어듭니다. 고정시간
  신호에서는 옵셋편의율과 녹색시간비로 〈표 8-17〉에서 구하며, **고립 교차로나 비연동 이동류는** $PF = 1.0$입니다.
- **추가지체 $d_3$** — 분석기간 시작 전 남아 있던 초기 대기행렬($Q_b$)이 있을 때만
  발생합니다. 초기 대기행렬이 없으면(계획·설계 분석 포함) $d_3 = 0$입니다.

## 5. 예제 — 지체 계산과 서비스수준

> **문제.** 제9강 예제의 차로군을 이어서 분석한다. 포화교통량 $S = 3{,}600$ vphg,
> 교통량 $V = 800$ vph, 녹색시간 $G = 40$초, 주기 $C = 120$초였고, 그 결과
> $g/C = 0.331$, 용량 $c = 1{,}192$ vph, 포화도 $X = 0.67$이었다. 고립 교차로($PF = 1.0$),
> 초기 대기행렬 없음, 분석기간 $T = 0.25$시간일 때 차량당 제어지체와 서비스수준은?

**균일지체 (식 8-47)**

$$d_1 = \frac{0.5 \times 120 \times (1 - 0.331)^2}{1 - 0.67 \times 0.331}
= \frac{60 \times 0.448}{0.778} \approx 34.5 \ \text{초}$$

**증분지체 (식 8-50)**

$$d_2 = 900 \times 0.25 \left[(0.67 - 1) + \sqrt{(0.67 - 1)^2 + \frac{4 \times 0.67}{1{,}192 \times 0.25}}\right]
\approx 3.0 \ \text{초}$$

**제어지체 (식 8-43)** — $PF = 1.0$, $d_3 = 0$.

$$d = d_1 \cdot PF + d_2 + d_3 = 34.5 \times 1.0 + 3.0 + 0 \approx 37.5 \ \text{초}$$

**서비스수준** — 〈표 8-2〉에서 37.5초는 B(≤ 30)를 넘고 C(≤ 50) 이하이므로 **서비스수준 C**
입니다.

| 서비스수준 | 차량당 제어지체 (초) |
| :---: | :---: |
| A | ≤ 15 |
| B | ≤ 30 |
| C | ≤ 50 |
| D | ≤ 70 |
| E | ≤ 100 |
| F | ≤ 220 |

## 6. 지체의 종합

지체는 **차로군별**로 구한 뒤, 상위 단위로 **교통량 가중평균**하여 종합합니다.

- 차로군별 제어지체 → 접근로별 제어지체(차로군 교통량으로 가중평균)
- 접근로별 제어지체 → 교차로 전체 평균 제어지체(접근로 교통량으로 가중평균)

각 단위마다 〈표 8-2〉로 서비스수준을 판정합니다. 앞서 강조했듯 **교차로 전체
서비스수준이 좋아도 특정 차로군은 매우 혼잡**할 수 있으므로, 차로군별 결과를 함께
보아야 합니다.

## 7. 요약

- 차량당 제어지체 $d = d_1 \cdot PF + d_2 + d_3$이며, 이 값으로 서비스수준을 판정한다.
- **균일지체** $d_1 = \dfrac{0.5\,C\,(1 - g/C)^2}{1 - \min(1,X)(g/C)}$ — 일정 도착 가정.
- **증분지체** $d_2 = 900\,T\left[(X-1) + \sqrt{(X-1)^2 + \dfrac{4X}{cT}}\right]$ — 과포화에 민감.
- **연동보정** $PF$는 균일지체에만, **추가지체** $d_3$는 초기 대기행렬이 있을 때만.
- 지체는 차로군 → 접근로 → 교차로로 **교통량 가중평균**해 종합한다.
