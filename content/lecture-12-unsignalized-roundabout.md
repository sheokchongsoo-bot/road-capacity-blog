> **강의 정보** · 교통용량분석 · 제12강 (120분)
> **교재**: 『도로용량분석의 이론과 실제』 · **근거 편람**: 『도로용량편람』(2013) 제10장 비신호교차로 · 제11장 회전교차로
> **선행 학습**: [제11강. 신호교차로 (4)](lecture-11-signalized-4.html)

신호교차로를 마치고, 이제 **신호 없이** 운영되는 교차로를 봅니다. 통행권을 시간으로
배분해 주는 신호가 없으므로, 운전자는 상충 교통류의 **차간시간(gap)을 스스로 골라**
통과해야 합니다. 이 원리가 **간격수락**이며, 비신호교차로와 회전교차로 분석의
공통 기반입니다.

## 학습 목표

1. **간격수락 이론**의 핵심 개념(임계간격·추종시간)을 안다.
2. **양방향정지·무통제 교차로**의 효과척도와 서비스수준을 판정한다.
3. **회전교차로**의 운영 원리와 용량·서비스수준 분석을 이해한다.

---

## 1. 간격수락 이론 — 공통 원리

신호가 없으면 부도로(또는 진입로) 차량은 우선권 있는 교통류의 **차간시간**을 이용해
횡단·합류합니다. 이때 두 파라미터가 분석의 핵심입니다.

- **임계간격(critical gap)** — 진입(횡단)이 가능한 차두시간의 **최소값**. 이보다 크면
  진입하고, 작으면 기다린다.
- **추종시간(follow-up time)** — 하나의 긴 차간시간에 **두 대 이상이 연속 진입**할 때의
  최소 차두시간.

상충 교통량이 많을수록 쓸 만한 간격이 드물어져 **용량이 줄어드는** 구조입니다.

## 2. 비신호교차로

### 유형과 분석 대상

비신호교차로는 **무통제 · 양방향정지 · 전방향정지 · 로터리식**의 네 유형으로 나뉘며,
편람은 국내 대표 유형인 **무통제 교차로**와 **양방향정지 교차로**의 분석 방법을
제시합니다. 중차량은 승용차환산계수 **1.8**을 일괄 적용합니다.

### 양방향정지 교차로

주도로 차량이 우선하고, 부도로 진입 차량과 주도로 좌회전 차량이 기다리는 방식입니다.
**진입 우선순위**는 다음과 같습니다.

1. 부도로 우회전 → 2. 주도로 좌회전 → 3. 부도로 직진 → 4. 부도로 좌회전

분석은 8단계로 진행합니다: 자료 입력 → **상충교통류 산정** → **임계간격·추종시간** →
이동류의 **잠재용량** → 저항계수 → 차로배분용량 → **운영지체** → 서비스수준 판정.

효과척도는 **평균운영지체**이며, 서비스수준은 〈표 10-2〉로 판정합니다.

| 서비스수준 | 평균운영지체 (초/대) |
| :---: | :---: |
| A | ≤ 10 |
| B | ≤ 15 |
| C | ≤ 25 |
| D | ≤ 35 |
| E | ≤ 50 |
| F | > 50 |

신호교차로(A ≤ 15초)보다 기준이 **엄격**합니다. 비신호교차로 이용자는 지체에 대한
기대 수준이 다르기 때문입니다. 또한 비신호교차로에서는 **서비스수준 E를 용량 상태로
정의할 수 없습니다**.

### 무통제 교차로

통제 시설이 전혀 없는, 교통량이 적은 교차로입니다. 효과척도는 **교차로 진입 교통량**과
**시간당 상충횟수**입니다. 분석은 네 단계로 간단합니다: 방향별 교통량 입력 → 중차량
보정(PCE 1.8) → **주도로 교통량비** 산정 → 서비스수준 판정(〈표 10-4〉).

〈표 10-4〉 무통제 교차로의 서비스수준 (교차로 총 진입교통량, vph)

| LOS | 주도로 비율 < 60% | < 70% | ≥ 70% | 시간당 상충횟수 |
| :---: | :---: | :---: | :---: | :---: |
| A | ≤ 320 | ≤ 360 | ≤ 400 | ≤ 60 |
| B | ≤ 640 | ≤ 720 | ≤ 800 | ≤ 120 |
| C | ≤ 960 | ≤ 1,080 | ≤ 1,200 | ≤ 180 |
| D | ≤ 1,280 | ≤ 1,440 | ≤ 1,600 | ≤ 240 |
| E | ≤ 1,600 | ≤ 1,800 | ≤ 2,000 | ≤ 300 |
| F | > 1,600 | > 1,800 | > 2,000 | > 300 |

**주도로 교통량비가 높을수록** 같은 서비스수준에서 더 많은 교통량을 처리합니다 —
교통량이 한 방향에 몰릴수록 상충이 줄어들기 때문입니다.

### 예제 1 — 무통제 교차로

> **문제.** 네갈래 무통제 교차로. 승용차 환산 후 방향별 진입교통량이 A·B 가로 400 vph,
> C·D 가로 600 vph이다. 서비스수준은?

**주도로 판정** — C·D 가로(600)가 A·B(400)보다 크므로 주도로.

$$\text{주도로 교통량비} = \frac{600}{400 + 600} = 60\%$$

**판정** — 총 진입교통량 1,000 vph, 주도로 비율 60%(< 70% 열 적용)에서 C(≤ 1,080)에
해당하므로 **서비스수준 C**입니다.

## 3. 회전교차로

### 정의와 운영 원리

> **회전교차로**: 신호 없이 교차로 중앙의 **원형교통섬**을 중심으로 회전하여 통과하는
> 평면교차로. **진입 차량이 회전 중인 차량에게 양보**하는 것이 기본 원리다.

통행우선권이 **회전차로 내부의 회전교통류**에 있으므로, 진입 차량은 회전차로에
안전한 간격이 생길 때까지 정지선에서 대기합니다. 일반 교차로보다 **상충 횟수가 현저히
적고** 저속으로 운영되어 안전합니다.

기본유형은 소형·**1차로형**·**2차로형**으로 나뉘며, 편람은 1차로형(계획교통량 일 2만 대
수준)과 2차로형(일 3.2만 대 수준)의 분석 방법을 제시합니다.

### 용량 분석 — 간격수락 모형

진입로 용량은 **간격수락 이론**에 근거한 분석적 모형(식 11-2)으로 구합니다. 입력은
**상충교통량**(진입 교통류와 상충하는 회전교통류, 식 11-1), 운전자 특성 파라미터,
진입차로수·횡단보행자 영향계수입니다. 편람이 제시하는 파라미터는 다음과 같습니다.

| 파라미터 | 1차로형 | 2차로형 |
| --- | :---: | :---: |
| 임계간격 (초) | 3.21 | 3.21 |
| 추종시간 (초) | 3.15 | 3.15 |
| 회전차로 최소 차두간격 (초) | 2.05 | 2.05 |
| 진입차로수 영향계수 | 1.0 | 1.7 |

**상충교통량이 클수록 진입 용량이 작아지고**, 2차로형은 진입차로수 영향계수(1.7)만큼
용량이 커집니다(단, 2배가 아닌 이유는 바깥차로로 이용이 몰리기 때문).

### 서비스수준 — 〈표 11-1〉

효과척도는 신호교차로와 같은 **차량당 평균지체**입니다. 접근로별 지체를 교통량
가중평균해 교차로 평균지체를 구하고, 6단계로 판정합니다.

| 서비스수준 | 평균지체 (초/대) | $V/c$ |
| :---: | :---: | :---: |
| A | ≤ 10 | ≤ 1.0 |
| B | ≤ 15 | ≤ 1.0 |
| C | ≤ 25 | ≤ 1.0 |
| D | ≤ 35 | ≤ 1.0 |
| E | ≤ 50 | ≤ 1.0 |
| F | > 50 | > 1.0 |

양방향정지 교차로(〈표 10-2〉)와 같은 지체 경계를 씁니다.

### 예제 2 — 회전교차로 서비스수준

> **문제.** 1차로형 회전교차로의 접근로별 평균지체가 북 12초(400 vph), 남 8초(300 vph),
> 동 20초(500 vph), 서 15초(300 vph)로 산출되었다. 교차로 서비스수준은?

**교차로 평균지체** — 접근로 지체를 교통량으로 가중평균.

$$d = \frac{12 \times 400 + 8 \times 300 + 20 \times 500 + 15 \times 300}{400 + 300 + 500 + 300}
= \frac{21{,}700}{1{,}500} \approx 14.5 \ \text{초/대}$$

**판정** — 〈표 11-1〉에서 14.5초는 B(≤ 15)에 해당하므로 **서비스수준 B**입니다.

## 4. 세 교차로 비교

| 시설 | 통행권 배분 | 효과척도 | LOS 등급 |
| --- | --- | --- | :---: |
| 신호교차로 | 신호(시간 배분) | 차량당 제어지체 | A–FFF 8단계 |
| 양방향정지 교차로 | 우선순위 + 간격수락 | 평균운영지체 | A–F 6단계 |
| 무통제 교차로 | 선착순 + 운전자 판단 | 진입 교통량·상충횟수 | A–F 6단계 |
| 회전교차로 | 회전차량 우선 + 간격수락 | 차량당 평균지체 | A–F 6단계 |

교통량이 적을 때는 비신호·회전교차로가 지체가 작고 효율적이지만, 교통량이 늘면
간격이 부족해져 신호 운영이 필요해집니다.

## 5. 요약

- 신호가 없는 교차로는 **간격수락**(임계간격·추종시간)으로 통행권을 얻는다.
- **양방향정지 교차로**는 평균운영지체(〈표 10-2〉), **무통제 교차로**는 진입 교통량·
  상충횟수(〈표 10-4〉)로 판정하며, 중차량 PCE는 일괄 **1.8**이다.
- **회전교차로**는 회전차량 우선 원칙 아래 간격수락 모형으로 용량을 구하고, 신호교차로와
  같은 **평균지체**로 서비스수준(A–F)을 판정한다.
- 비신호 계열에서는 **서비스수준 E ≠ 용량 상태**임에 유의한다.

## 참고 — 미국 HCM(7판)과의 비교

- 비신호·회전교차로의 지체 기준(10 / 15 / 25 / 35 / 50초)은 **KHCM과 동일**합니다 —
  KHCM이 이 기준 체계를 준용했습니다.
- 단, HCM은 **포화도가 1.0을 넘으면 지체가 작아도 LOS F**로 처리합니다.
- 회전교차로 용량은 임계간격·추종시간에서 유도한 **지수 회귀모형**
  $c = A\,e^{-B\,v_c}$ 형태이며, 미국 운전자의 임계간격이 한국 관측값(3.21초)보다
  길게 나타나 같은 상충교통량에서도 용량이 다르게 산정됩니다.
- 7판에서 회전교차로와 램프 터미널(연결로-일반도로 접속부) 방법이 갱신되었습니다.

2차로도로)와 단속류(신호·비신호·회전교차로)의 분석 절차, 핵심 공식·표를 총정리하고
빈출 유형을 짚습니다. 기말고사 대비의 마지막 강의입니다.

### 복습 문제

1. 임계간격과 추종시간의 차이를 설명하시오.
2. 양방향정지 교차로에서 부도로 좌회전의 우선순위가 가장 낮은 이유는? (상충 관점)
3. 무통제 교차로에서 주도로 교통량비가 높을수록 처리 가능 교통량이 커지는 이유는?
