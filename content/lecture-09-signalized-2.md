제8강에서 **포화교통류율** $S$와 **손실시간**을 배웠습니다. 이번 강의에서는 손실시간에서
**유효녹색시간**을 구하고, 이를 이용해 신호교차로 용량 분석의 핵심인 **용량**과
**포화도**, 그리고 **임계 $V/c$비**를 계산합니다.

## 학습 목표

1. 손실시간에서 **유효녹색시간**과 녹색시간비 $g/C$를 구한다.
2. 차로군 **용량** $c = S(g/C)$와 **포화도** $X = V/c$를 계산한다.
3. **임계차로군**을 찾아 교차로의 **임계 $V/c$비**를 종합한다.
4. 3현시 교차로에서 유효녹색을 배분하고, 미국 HCM 기준과 비교한다.

## 1. 유효녹색시간

한 현시의 녹색·황색시간이 모두 쓰이지는 않습니다. 출발손실(2.3초)과 진행연장(2.0초)을
반영하면, 실제로 차량이 쓰는 **유효녹색시간**은 녹색시간에서 그 차이 **0.3초**를 뺀
값이 됩니다.

$$g = G - 0.3 \qquad (\text{초})$$

여기서 $G$는 녹색신호시간입니다(출발손실 2.3 − 진행연장 2.0 = 0.3초). 이 유효녹색시간을
주기로 나눈 **녹색시간비** $g/C$가 용량 산정의 핵심 변수입니다.

한편 **현시당 손실시간**은 표시된 녹색+황색에서 유효녹색을 뺀 값, 즉 **황색시간 + 0.3초**
입니다(출발손실 2.3초는 그대로 손실, **소거손실 = 황색 − 2.0초**). $n$개 현시의
**주기당 총 손실시간**은

$$L = \sum_{i=1}^{n} (Y_i + 0.3)$$

## 2. 차로군 용량과 포화도

차로군의 **용량**은 포화교통류율에 녹색시간비를 곱한 값입니다.

$$c_i = S_i \times \frac{g_i}{C} \qquad (\text{식 8-40})$$

**교통량비**(flow ratio) $y_i = V_i / S_i$는 교통량을 포화교통량으로 나눈 값이고,
**포화도**(degree of saturation) $X_i = V_i / c_i$는 교통량 대 용량비입니다. 셋의 관계는

$$X_i = \frac{V_i}{c_i} = \frac{V_i}{S_i\,(g_i/C)} = \frac{y_i}{g_i/C}$$

$X$는 보통 0–1.0이며, 도착 교통량이 용량을 넘으면 1.0을 초과합니다.

> 한 접근로의 여러 차로군 용량을 **합하는 것은 의미가 없습니다**. 서로 다른 이동류의
> 용량을 더하는 셈이기 때문입니다. 교차로 전체 용량도 마찬가지입니다.

### 서비스수준 기준 — 〈표 8-2〉

포화도는 용량의 여유일 뿐, 운전자가 겪는 불편은 아닙니다. 서비스수준은 $X$가 아니라
**차량당 제어지체**로 판정하며 **8단계**로 세분합니다(〈표 8-2〉). 제10강에서 지체를
계산해 이 표에 대입하는데, 바로 아래 예제 1의 차로군도 그때 지체 약 37.5초로 **C**가 됩니다.

| 서비스수준 | 차량당 제어지체 (초) |
| :---: | :---: |
| A | ≤ 15 |
| B | ≤ 30 |
| C | ≤ 50 |
| D | ≤ 70 |
| E | ≤ 100 |
| F | ≤ 220 |
| FF | ≤ 340 |
| FFF | > 340 |

### 예제 1 — 유효녹색 → 용량 → 포화도

> **문제.** 어느 차로군의 포화교통량 $S = 3{,}600$ vphg, 교통량 $V = 800$ vph이다.
> 녹색시간 $G = 40$초, 주기 $C = 120$초일 때 용량과 포화도는?

**유효녹색시간과 녹색시간비**

$$g = 40 - 0.3 = 39.7 \ \text{초}, \qquad \frac{g}{C} = \frac{39.7}{120} \approx 0.331$$

**용량**

$$c = S \times \frac{g}{C} = 3{,}600 \times 0.331 \approx 1{,}192 \ \text{vph}$$

**포화도**

$$X = \frac{V}{c} = \frac{800}{1{,}192} \approx 0.67$$

교통량비 $y = V/S = 800/3{,}600 \approx 0.222$이며, $X = y/(g/C) = 0.222/0.331 \approx 0.67$로
일치합니다.

## 3. 임계차로군과 임계 V/c비

신호교차로의 용량은 각 **차로군**별로 구하지만, 신호시간을 좌우하는 것은 각 현시에서
가장 바쁜 차로군입니다.

> **임계차로군(critical lane group)**: 한 신호현시에서 진행하는 차로군 중 교통량비
> $y = V/S$가 **가장 큰** 차로군.

각 현시의 임계차로군 교통량비를 모두 더하면, 교차로 전체의 **임계 $V/c$비**를 구할 수
있습니다(식 8-42).

$$X_c = \frac{C}{C - L}\sum_{i} y_{ci}$$

여기서 $L$은 주기당 총 손실시간, $y_{ci}$는 각 현시 임계차로군의 교통량비입니다.

> **주의**: 임계 $V/c$비는 **적정 신호운영**을 전제로 한 교차로 혼잡도 지표입니다.
> 신호운영이 나쁘면 어느 차로군의 $V/c$가 1.0을 넘어도 임계 $V/c$비는 낮게 나올 수
> 있으므로, 이 값만으로 교차로 전체 서비스수준을 단정해서는 안 됩니다.

### 예제 2 — 임계 V/c비

> **문제.** 2현시로 운영되는 교차로. 현시 1의 임계차로군 $y_{c1} = 0.30$, 현시 2의
> $y_{c2} = 0.25$이다. 주기 $C = 120$초, 각 현시 황색 3초일 때 임계 $V/c$비는?

**주기당 손실시간** — 현시당 손실 = 황색 + 0.3초.

$$L = 2\,(3 + 0.3) = 6.6 \ \text{초}$$

**임계 $V/c$비**

$$X_c = \frac{120}{120 - 6.6}\,(0.30 + 0.25) = \frac{120}{113.4}\times 0.55 \approx 0.58$$

임계 $V/c$비 0.58은 이 교차로가 적정 신호운영 하에서 용량에 어느 정도 여유가 있음을
뜻합니다.

### 예제 3 — 3현시 교차로의 임계 V/c비

> **문제.** 주기 $C = 120$초, 3현시(각 황색 3초) 교차로의 차로군별 교통량·포화교통량이
> 아래와 같다. 임계 $V/c$비와 현시별 유효녹색시간은?

| 현시 | 차로군 | V (vph) | S (vphg) | y = V/S |
| :---: | :--- | ---: | ---: | ---: |
| 1 | 동측 직진(2차로) | 1,300 | 4,400 | **0.295** |
| 1 | 서측 직진(2차로) | 1,150 | 4,400 | 0.261 |
| 2 | 남측 직진(2차로) | 680 | 3,400 | **0.200** |
| 2 | 북측 직진(2차로) | 510 | 3,400 | 0.150 |
| 3 | 동측 좌회전(보호) | 250 | 1,800 | **0.139** |
| 3 | 서측 좌회전(보호) | 180 | 1,800 | 0.100 |

$y$가 가장 큰 차로군이 임계차로군이므로 $y_{c1} = 0.295$, $y_{c2} = 0.200$, $y_{c3} = 0.139$,
합은 $\sum_i y_{ci} = 0.634$입니다. 주기당 손실은 $L = 3(3 + 0.3) = 9.9$초이므로

$$X_c = \frac{120}{120 - 9.9} \times 0.634 = 1.090 \times 0.634 \approx 0.69$$

**유효녹색 배분** — 손실을 뺀 $C - L = 110.1$초를 $y_{ci}$ 비율로 나눕니다.

$$g_1 = \frac{0.295}{0.634}\times 110.1 \approx 51.2,\quad
g_2 = \frac{0.200}{0.634}\times 110.1 \approx 34.7,\quad
g_3 = \frac{0.139}{0.634}\times 110.1 \approx 24.1 \ \text{초}$$

이때 세 임계차로군의 포화도가 모두 같아집니다(등포화도 배분). 동측 직진으로 검산하면
$g_1/C = 0.427$, $c = 4{,}400 \times 0.427 \approx 1{,}878$ vph, $X = 1{,}300/1{,}878 \approx 0.69$로
임계 $V/c$비와 같고, 표시 녹색 $G_i = g_i + 0.3$초에 황색 3초를 더하면 주기가 120초가 됩니다.

> **해석**: 0.69는 아직 여유가 있다는 뜻입니다. 다만 $\sum y_{ci}$에 보호좌회전 현시가
> 포함되므로 좌회전 교통량이 늘면 신호시간을 다시 배분해야 합니다.

## 4. 요약

- **유효녹색시간** $g = G - 0.3$초, **녹색시간비** $g/C$. 현시당 손실 = 황색 + 0.3초.
- 차로군 **용량** $c = S(g/C)$, **교통량비** $y = V/S$, **포화도** $X = V/c = y/(g/C)$.
- **임계차로군**은 각 현시에서 $y$가 최대인 차로군이며, **임계 $V/c$비**
  $X_c = \dfrac{C}{C-L}\sum y_{ci}$로 교차로 혼잡도를 나타낸다(절대 신뢰는 금물).
- 주기는 **유효녹색 합계 $C - L$**과 손실로 나뉘고, $C-L$을 $y_{ci}$로 배분하면 임계차로군의
  $X$가 모두 같아진다. 서비스수준은 **A–FFF 8단계**의 지체로 판정한다.

## 참고 — 미국 HCM(7판)과의 비교

- 기본 포화교통류율은 **1,900 pc/h/ln**으로 KHCM(2,200)보다 약 14% 작습니다.
- 출발손실·진행연장을 모두 **2.0초**로 보아 현시당 손실이 사실상 황색시간과 같습니다.
  KHCM은 출발손실 2.3초라 **황색 + 0.3초**가 되어 손실이 더 큽니다.
- 서비스수준 경계는 제어지체 **10 / 20 / 35 / 55 / 80초**의 6단계(A–F)로, 한국
  (15 / 30 / 50 / 70 / 100 / 220 / 340초, 8단계)보다 이른 지체에서 등급이 떨어집니다.
  지체 45초는 미국 기준 **D**, 한국 기준 **C**입니다.
- HCM은 **$V/c > 1.0$이면 지체와 무관하게 LOS F**로 판정하고, KHCM은 지체로 판정하되 F를
  FF·FFF로 세분합니다. 임계 $V/c$비 산식은 두 기준이 사실상 같으므로, 시험에서는 KHCM
  값(2,200, 15/30/…)으로 답합니다.
