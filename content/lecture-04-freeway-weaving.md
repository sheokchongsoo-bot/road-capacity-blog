제2·3강에서 다룬 **기본구간**은 합류·분류·엇갈림의 영향이 없는 순수 본선이었습니다.
이번 강의부터는 교통류가 서로 간섭하는 구간을 다룹니다. 그 첫 번째가 두 교통류가
서로 자리를 바꾸는 **엇갈림구간**입니다.

## 학습 목표

1. **엇갈림**의 정의와 엇갈림·비엇갈림 교통류를 구분한다.
2. 두 가지 엇갈림 **형태**(본선-연결로, 연결로-연결로)와 영향 요소를 안다.
3. **밀도**를 주효과척도로 엇갈림구간의 **서비스수준을 판정**한다.

---

## 1. 엇갈림이란

> **엇갈림(weaving)**: 교통통제 시설의 도움 없이 상당히 긴 도로를 따라가면서 동일
> 방향의 두 교통류가 서로 엇갈리며 차로를 변경하는 현상.

엇갈림구간은 **합류 구간 바로 다음에 분류 구간**이 있거나, **유입 연결로 바로 다음에
유출 연결로**가 있어 이 두 지점이 연속된 보조차로로 연결될 때 생깁니다. 이 구간에서
교통류는 두 종류로 나뉩니다.

- **엇갈림 교통류**($V_w$) — 원하는 방향으로 가려면 **반드시 차로를 바꿔야** 하는 흐름.
- **비엇갈림 교통류**($V_{nw}$) — 차로를 바꾸지 않아도 원하는 방향으로 갈 수 있는 흐름.

엇갈림구간은 필수적인 차로 변경이 집중되어 상충 빈도가 높고, 그만큼 혼잡·사고
가능성이 큽니다. 그래서 설계 단계부터 세심하게 다루어야 합니다.

## 2. 두 가지 엇갈림 형태

편람은 국내에서 가장 전형적인 두 형태를 다룹니다. 두 형태 모두 각 엇갈림 차량이
**한 번의 차로 변경**을 하게 됩니다.

- **본선-연결로 엇갈림**(ramp weave) — 본선 한쪽에 유입 연결로 다음 유출 연결로가
  보조차로로 이어진 형태. 엇갈림이 **본선에서** 일어난다.
- **연결로-연결로 엇갈림**(frontage weave) — 엇갈림을 본선이 아니라 본선에 붙은
  집산도로(측도)에서 일어나게 한 형태. 고속 본선에서 엇갈림을 떼어낸 **바람직한 설계**.

## 3. 엇갈림에 영향을 주는 세 요소

엇갈림구간의 운영 상태는 다음 세 가지 기하구조 요소에 좌우됩니다.

1. **형태** — 차로 변경 횟수와 출입 위치. 변경이 잦을수록 서비스수준이 나빠진다.
2. **길이**($L$) — 진입로가 본선과 만나는 지점부터 진출로 시작부까지의 거리.
   짧을수록 차로 변경이 어려워 혼란이 커진다.
3. **폭**(차로수 $N$) — 넓을수록 엇갈림의 영향이 작아진다.

**엇갈림 구간 길이의 기준**

- 본선-연결로: 최소 **200 m** 이상 권장. **750 m**를 넘으면 엇갈림이라기보다 합류·분류가
  독립적으로 작용하므로, **연결로 접속부**(제5강)로 나누어 분석한다.
- 연결로-연결로: 최소 **150 m**.

## 4. 핵심 변수와 적용 한계

| 기호 | 의미 |
| :---: | --- |
| $V$ | 엇갈림 구간의 총 교통량 (pcph) |
| $V_w,\ V_{nw}$ | 엇갈림 · 비엇갈림 교통량 (pcph) |
| $\mathrm{VR}$ | 교통량 비 $= V_w / V$ |
| $N$ | 엇갈림 구간의 총 차로수 |
| $L$ | 엇갈림 구간 길이 (m) |
| $S_w,\ S_{nw}$ | 엇갈림 · 비엇갈림 교통류의 평균 속도 (kph) |

방법론을 적용하려면 다음 **변수 한계**를 만족해야 합니다(본선-연결로 기준).

| 본선 차로수 | 총 차로수 $N$ | $\mathrm{VR}$ 한계 |
| :---: | :---: | :---: |
| 2 | 3 | ≤ 0.50 |
| 3 | 4 | ≤ 0.45 |
| 4 | 5 | ≤ 0.40 |

- 총 교통량: $V/N \le 2{,}000$ pcphpl
- 엇갈림 교통량: $V_w \le 2{,}800$ pcph (본선-연결로), $\le 3{,}000$ pcph (연결로-연결로)

## 5. 분석 절차 — 밀도로 판정

엇갈림구간의 주효과척도는 **밀도**입니다. 운영 분석은 다음 순서로 진행합니다.

**① 첨두시간 승용차 교통량 환산** — 1시간 교통량을 PHF와 중차량 보정계수로 나눠
승용차 단위 교통류율로 바꿉니다.

$$V_p = \frac{V}{\mathrm{PHF} \times f_{HV}} \qquad (\text{식 3-6})$$

(PHF는 현장 조사, 없으면 도시부 0.90–지방부 0.95를 적용하며, 승용차환산계수는
고속도로 기본구간 값을 씁니다.)

**② 평균 속도** — 엇갈림·비엇갈림 속도를 교통량으로 가중한 조화평균으로 구합니다.

$$S = \cfrac{V}{\cfrac{V_w}{S_w} + \cfrac{V_{nw}}{S_{nw}}} \qquad (\text{식 3-4})$$

**③ 평균 밀도** — 차로당 교통류율을 평균 속도로 나눕니다.

$$D = \frac{V/N}{S} \qquad (\text{식 3-5})$$

**④ 서비스수준 판정** — 산출한 밀도 $D$를 〈표 3-1〉과 비교합니다.

> 계획·설계 단계에서는 $S_w$, $S_{nw}$를 편람의 속도 추정식(식 3-1–3-3)으로 구하고,
> 운영 단계에서는 현장 조사로 얻습니다. 이 강의에서는 속도가 주어졌다고 보고
> 밀도 판정에 집중합니다.

## 6. 서비스수준 판정표

〈표 3-1〉은 엇갈림구간의 밀도 기준 서비스수준입니다. 본선에서 엇갈림이 일어나는
본선-연결로보다, 저속 측도에서 처리하는 연결로-연결로의 기준이 더 완화되어 있습니다.

| 서비스수준 | 본선-연결로 (pcpkmpl) | 연결로-연결로 (pcpkmpl) |
| :---: | :---: | :---: |
| A | ≤ 6  | ≤ 8  |
| B | ≤ 12 | ≤ 13 |
| C | ≤ 17 | ≤ 18 |
| D | ≤ 22 | ≤ 25 |
| E | ≤ 27 | ≤ 38 |
| F | > 27 | > 38 |

용량은 서비스수준 E의 최대 상태로 정의되며, 밀도로는 본선-연결로 **27 pcpkmpl**,
연결로-연결로 **37.5 pcpkmpl**에 해당합니다.

### 예제 — 본선-연결로 엇갈림구간 운영 분석

> **문제.** 본선 3차로에 보조차로가 더해진 총 $N = 4$차로, 길이 $L = 410$ m의 본선-연결로
> 엇갈림구간이다. 첨두시간 승용차 교통량으로 환산한 결과 총 $V = 5{,}470$ pcph, 이 중
> 엇갈림 $V_w = 1{,}400$ pcph, 비엇갈림 $V_{nw} = 4{,}070$ pcph이다. 현장에서 조사한
> 평균 속도가 엇갈림 $S_w = 75$ kph, 비엇갈림 $S_{nw} = 90$ kph일 때 서비스수준은?

**① 변수 한계 점검**

$$\mathrm{VR} = \frac{V_w}{V} = \frac{1{,}400}{5{,}470} \approx 0.26 \ (\le 0.45), \quad
\frac{V}{N} = \frac{5{,}470}{4} \approx 1{,}368 \ (\le 2{,}000)$$

$V_w = 1{,}400 \le 2{,}800$ 도 만족하므로 방법론을 적용할 수 있습니다.

**② 평균 속도 (식 3-4)**

$$S = \cfrac{5{,}470}{\cfrac{1{,}400}{75} + \cfrac{4{,}070}{90}}
= \frac{5{,}470}{18.67 + 45.22} \approx 85.6 \ \text{kph}$$

**③ 평균 밀도 (식 3-5)**

$$D = \frac{V/N}{S} = \frac{1{,}368}{85.6} \approx 16.0 \ \text{pcpkmpl}$$

**④ 서비스수준** — 〈표 3-1〉 본선-연결로에서 밀도 16은 B(≤ 12)와 C(≤ 17) 사이이므로
**서비스수준 C**입니다.

## 7. 요약

- **엇갈림**은 두 교통류가 차로를 바꿔 자리를 맞바꾸는 현상이며, 엇갈림($V_w$)·
  비엇갈림($V_{nw}$) 교통류로 나뉜다.
- 두 형태(본선-연결로 · 연결로-연결로)와 세 요소(형태 · 길이 $L$ · 폭 $N$)가 운영 상태를 좌우한다.
- 주효과척도는 **밀도**: $V_p$ 환산 → 평균 속도 $S$(식 3-4) → 밀도 $D$(식 3-5) → 〈표 3-1〉 판정.
- 적용 전 $\mathrm{VR}$, $V/N$, $V_w$의 한계를 반드시 점검한다.

## 참고 — 미국 HCM(7판)과의 비교

- KHCM이 엇갈림·비엇갈림 **속도**를 추정해 밀도로 가는 반면, HCM은 **차로변경 횟수**를
  중심에 둡니다 — 엇갈림에 필요한 최소 차로변경수와 엇갈림 이용 가능 차로수로
  속도·밀도를 추정합니다.
- **최대 엇갈림 길이** 개념이 있어, 이를 넘으면 합류·분류부로 나누어 분석합니다
  (KHCM의 750 m 기준과 같은 취지).
- LOS는 밀도로 판정하고 수요가 용량을 넘으면 F입니다. 7판은 120여 개 현장의 대규모
  검지기·프로브 자료로 방법론을 갱신했습니다.
