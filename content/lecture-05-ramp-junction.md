> **교재**: 『도로용량분석의 이론과 실제』 · **근거 편람**: 『도로용량편람』(2013) 제4장 고속도로 연결로 접속부
> **선행 학습**: [제4강. 고속도로 엇갈림구간](lecture-04-freeway-weaving.html)

연결로는 고속도로와 일반도로를 잇는 통로입니다. 연결로가 본선에 붙는 **접속부**에서는
차량이 **합류**하거나 **분류**하면서 본선 교통류를 흔듭니다. 이번 강의에서는 이
접속부의 영향권과 서비스수준을 분석합니다.

## 학습 목표

1. 연결로 접속부의 **합류부·분류부**와 **영향권**을 안다.
2. **용량 확인**으로 분석 진행 여부를 판단한다.
3. **영향권 밀도**를 주효과척도로 **서비스수준을 판정**한다.

---

## 1. 연결로 접속부란

> **연결로 접속부(Ramp-Freeway Junction)**: 고속도로 본선에 합류 또는 분류 연결로가
> 접속되는 구간.

두 교통수요가 경쟁적으로 상충하며 차로 변경이 잦아, 본선보다 불안정하고 혼잡·사고
가능성이 큰 구간입니다. 형태는 크게 둘로 나뉩니다.

- **합류부**(merge) — 연결로 유입 차량이 본선 차량과 주행권을 다투며 합쳐지는 구간.
- **분류부**(diverge) — 유출 차량이 접속 차로로 모여 본선에서 갈라지는 구간.

편람은 국내에서 가장 일반적인 **"분류 후 합류"** 형태를 기본으로 합니다. 두 연결로의
노면 표시 끝단 사이 거리가 **500 m를 넘으면** 분류부와 합류부를 **각각 독립 접속부로**
분석합니다. 분석 대상 연결로의 차로수는 1차로를 기본으로 합니다.

## 2. 영향권과 주효과척도

연결로 유출입 차량은 본선 차량의 주행에 영향을 주는데, 그 범위를 **영향권**이라
합니다.

- **합류부**: 합류가 시작되는 지점부터 **하류 방향 400 m**.
- **분류부**: 분류가 완료된 지점부터 **상류 방향 400 m**.
- 영향권에는 **보조차로 + 차로1(접속 차로) + 차로2**가 포함됩니다.

> 접속 차로에 인접한 본선 차로를 편의상 **차로1**, 그 옆을 **차로2**라 부릅니다.

연결로 접속부의 주효과척도는 **영향권의 밀도**입니다 — 접속 차로로부터 두 개 차로의
평균 밀도로 정의합니다.

## 3. 서비스수준 판정표

운행 특성상 연결로 접속부는 기본구간보다 서비스수준이 떨어지므로, 서비스수준 E를
**22 pcpkmpl**로 더 엄격하게 기준합니다.

| 서비스수준 | 영향권 밀도 (pcpkmpl) |
| :---: | :---: |
| A | ≤ 6 |
| B | ≤ 12 |
| C | ≤ 17 |
| D | ≤ 22 |
| E | > 22 |
| F | 용량 초과 |

> 서비스수준 F에 밀도 값이 없는 이유: 분석 절차에서 **용량을 초과하면** 밀도 예측
> 단계로 가지 않고 곧바로 F로 처리하기 때문입니다.

## 4. 분석 절차

운영 상태 분석은 다음 순서로 진행합니다(계획·설계도 수요 변수만 다를 뿐 개념은 동일).

**① 첨두시간 환산 교통량** — 본선·연결로 교통량을 각각 환산합니다.

$$V_p = \frac{V}{\mathrm{PHF} \times f_{HV}} \qquad (\text{식 4-1})$$

**② 용량 확인** — 환산 교통량을 〈표 4-1〉·〈표 4-2〉의 용량과 비교합니다. 한 지점이라도
용량을 넘으면 **분석을 중단하고 서비스수준 F**로 판정합니다.

〈표 4-1〉 연결로 접속부 용량 (본선, 단위 pcph)

| 본선 자유속도 | 편도 2차로 | 편도 3차로 | 차로당 | 유출부 | 유입부 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| ≤ 120 | ≤ 4,600 | ≤ 6,900 | ≤ 2,300 | 4,400 | 4,600 |
| ≤ 110 | ≤ 4,500 | ≤ 6,750 | ≤ 2,250 | 4,400 | 4,600 |
| ≤ 100 | ≤ 4,400 | ≤ 6,600 | ≤ 2,200 | 4,400 | 4,600 |
| ≤ 90  | ≤ 4,200 | ≤ 6,300 | ≤ 2,100 | 4,400 | 4,600 |

〈표 4-2〉 연결로 용량 (단위 pcph)

| 연결로 자유속도 | 1차로 | 2차로 |
| :---: | :---: | :---: |
| > 70 | ≤ 2,000 | ≤ 4,000 |
| ≤ 70 | ≤ 1,900 | ≤ 3,800 |
| ≤ 60 | ≤ 1,800 | ≤ 3,600 |
| ≤ 50 | ≤ 1,700 | ≤ 3,400 |
| ≤ 40 | ≤ 1,600 | ≤ 3,200 |

**③ 영향권 교통량 $V_{12}$** — 본선 교통량 중 차로1·차로2로 오는 양을 **영향권 비**로
구합니다.

$$\text{합류부: } V_{12} = V_F \times P_{FM}, \qquad
\text{분류부: } V_{12} = V_R + (V_F - V_R)\times P_{FD}$$

영향권 비는 본선 차로수와 접속 형태에 따라 〈표 4-4〉·〈표 4-5〉에서 구합니다. 가장
간단한 **편도 2차로**는 $P_{FM} = P_{FD} = 1.00$이고, 예컨대 **편도 3차로 독립 합류부**는
$P_{FM} = 0.5127 + 0.000193\,V_R$ 처럼 회귀식으로 계산합니다.

**④ 영향권 밀도** — 합류부·분류부 각각의 예측식으로 밀도를 구합니다.

$$D_{MR} = 0.2048 + 0.003185\,V_R + 0.005989\,V_{12} - 0.00101\,L_A \quad (\text{식 4-13})$$

$$D_{DR} = 0.5108 + 0.00589\,V_{12} - 0.0043\,L_D \quad (\text{식 4-14})$$

여기서 $L_A$, $L_D$는 가속·감속 차로 길이(m)입니다.

**⑤ 서비스수준 판정** — 산출한 밀도를 〈표 4-3〉과 비교합니다.

### 예제 — 독립 합류 연결로 접속부

> **문제.** 본선 편도 2차로(양방향 4차로)에 1차로 합류 연결로가 독립적으로 접속한다.
> 본선 자유속도 100 km/h, 평지, 차로폭 3.5 m. 본선 교통량 2,900 vph(트럭 10%),
> 연결로 교통량 550 vph(트럭 4%), $\mathrm{PHF} = 0.90$, 가속차로 $L_A = 225$ m,
> 연결로 자유속도 70 km/h. 첨두시간 서비스수준은?

**① 첨두시간 환산** — 승용차환산계수는 기본구간 값(중형 $E=1.5$)을 사용.

$$f_{HV,\text{본선}} = \frac{1}{1 + 0.10(1.5-1)} \approx 0.95, \quad
V_F = \frac{2{,}900}{0.90 \times 0.95} \approx 3{,}392 \ \text{pcph}$$

$$f_{HV,\text{연결로}} = \frac{1}{1 + 0.04(1.5-1)} \approx 0.98, \quad
V_R = \frac{550}{0.90 \times 0.98} \approx 624 \ \text{pcph}$$

**② 영향권 교통량** — 편도 2차로이므로 $P_{FM} = 1.00$.

$$V_{12} = V_F \times P_{FM} = 3{,}392 \times 1.00 = 3{,}392 \ \text{pcph}$$

**③ 용량 확인** — 〈표 4-1〉(100 km/h)·〈표 4-2〉(70 km/h, 1차로)와 비교.

- 합류부 하류: $V_{FO} = V_F + V_R = 4{,}016 \le 4{,}400$ ✓
- 유입부: $V_{R12} = V_R + V_{12} = 4{,}016 \le 4{,}600$ ✓
- 연결로: $624 \le 1{,}900$ ✓ → 모두 통과, 분석 진행.

**④ 영향권 밀도 (식 4-13)**

$$D_{MR} = 0.2048 + 0.003185(624) + 0.005989(3{,}392) - 0.00101(225) \approx 22.3 \ \text{pcpkmpl}$$

**⑤ 서비스수준** — 〈표 4-3〉에서 밀도 22.3은 22를 넘으므로 **서비스수준 E**입니다.

## 5. 계획·설계 분석

계획·설계에서는 장래 교통수요로 차로수를 정하고 서비스수준을 분석합니다. 첨두시간
교통수요는 다음과 같이 산출합니다.

$$\text{첨두시간 교통량} = \frac{\mathrm{DDHV}}{\mathrm{PHF} \times f_{HV}}
= \frac{\mathrm{AADT} \times K \times D}{\mathrm{PHF} \times f_{HV}} \qquad (\text{식 4-15})$$

설계 서비스수준은 도시지역 **D**, 지방지역 **C**를 적용하며, 연결로 유출입부는 다음
**차로 균형** 원칙을 따릅니다.

- 합류부: (합류 후 차로수) ≥ (합류 전 전체 차로수) − 1
- 분류부: (분류 전 차로수) ≥ (분류 후 전체 차로수) − 1

## 6. 요약

- 연결로 접속부는 **합류부·분류부**로 나뉘며, 500 m를 넘게 떨어지면 각각 독립 분석한다.
- 주효과척도는 **영향권 밀도**(접속 차로부터 두 개 차로, 400 m 영향권).
- 절차: 환산(식 4-1) → **용량 확인**(초과 시 F) → 영향권 교통량 $V_{12}$ → 밀도(식 4-13·4-14) → 〈표 4-3〉 판정.
- 서비스수준 E 기준이 **22 pcpkmpl**로, 기본구간보다 엄격하다.

## 참고 — 미국 HCM(7판)과의 비교

- 영향권은 고어부 기준 **1,500 ft**(약 457 m)로 KHCM의 400 m와 같은 취지이며, 인접
  연결로가 3,000 ft(약 914 m) 이내면 영향권 중첩을 고려합니다.
- 접속 차로 두 개의 교통량 $V_{12}$를 영향권 비 회귀식으로 추정하는 골격은
  동일합니다 — KHCM 방법의 원형이 HCM입니다.
- 영향권 밀도 기준: A ≤ 10, B ≤ 20, C ≤ 28, D ≤ 35, E > 35 pc/mi/ln이며, 수요가
  용량을 넘으면 F입니다.

### 복습 문제

1. 합류부와 분류부의 영향권을 각각 어떻게 정의하는가? (기준점과 방향, 거리)
2. 용량 확인 단계에서 한 지점이라도 용량을 초과하면 서비스수준을 어떻게 처리하는가?
3. 예제에서 본선 교통량이 3,400 vph로 늘면 $V_F$, $V_{12}$, 밀도, 서비스수준은 어떻게 바뀌는가?
4. 편도 3차로 독립 합류부에서 $V_R = 700$ pcph일 때 $P_{FM}$을 구하시오. (식 4-5)
5. 연결로 접속부의 서비스수준 E 기준이 왜 기본구간보다 낮은 밀도(22 pcpkmpl)로 설정되었는지 설명하시오.
