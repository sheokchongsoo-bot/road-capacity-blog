# 그룹웨어 게시글용 설치 안내문

아래 내용을 사내 그룹웨어 게시판/자료실 **새 글 본문**에 붙여넣고,
**`oimarket-0.1.0.apk` 파일을 첨부**해서 올리면 됩니다.
(install.html·qr.svg·version.json 은 웹서버 배포용이라 이 경우 사용하지 않습니다.)

---

## [사내 앱] 오이마켓 — 안드로이드 설치 안내

**■ 소개**
오이마켓은 인천연구원 직원끼리 중고물품·재능을 나누는 **사내 전용 앱**입니다. (안드로이드 전용)

**■ 다운로드**
이 글에 **첨부된 파일을 휴대폰에서** 내려받으세요.
- 파일: `oimarket-0.1.0.apk`
- 버전: 0.1.0 · 용량: 약 2.5 MB
- 필요 사양: **Android 8.0 이상**
- 무결성(SHA-256): `c8d04e2e8c3b721dd0dc8bf4912a982910b87cc8be5edeb2ccf0f9ce763b0498`

**■ 설치 방법 (약 1분)**
1. 위 첨부파일 `oimarket-0.1.0.apk` 를 눌러 내려받습니다.
2. 설치가 막히면, 뜨는 안내에서 **[설정 → 이 출처의 앱 설치 허용]** 을 켭니다. (사용한 앱 기준, 최초 1회)
3. 내려받은 파일을 열고 **[설치]** 를 누릅니다.
4. “알 수 없는 앱”(Play Protect) 경고가 뜨면, 사내 배포 앱이므로 **[무시하고 설치]** 를 선택합니다.

**■ 주의**
- 인천연구원 **내부 배포용** 앱입니다. 외부로 공유하지 마세요.
- 개인정보·거래 내용은 **본인 휴대폰 안에만** 저장됩니다.
- 거래는 직원 간 **직거래(원내 직접 만남)** 를 원칙으로 합니다.

**■ 문의**
- (담당 부서 / 연락처를 넣으세요)

## 업데이트 배포 방법 (다음 버전)
- 앱 `versionCode`·`versionName` 을 올려 다시 서명 빌드 → 같은 게시판에 **새 APK 를 새 글로** 올리고 공지.
- (그룹웨어 첨부는 고정 URL 이 없어 자동 업데이트는 동작하지 않습니다. 자동 업데이트가 필요하면
  추후 사내 클라우드/웹에 `version.json` 을 고정 주소로 올리는 방식으로 전환하면 됩니다.)
