# 인천연구원 나눔장터 (MVP 프로토타입)

인천연구원 원내 직원끼리 **중고물품·재능**을 거래하는 "당근마켓의 원내 버전" 프로토타입입니다.
프레임워크 없이 **순수 HTML/CSS/JS**로 만든 **PWA(설치형 웹앱)** 이며, 데이터는
브라우저(`localStorage`)에만 저장됩니다. 서버·외부 전송이 없습니다.

> 이 저장소(블로그)와는 별개인 실험적 프로토타입으로, `app/` 안에 자체 완결형으로 담겨 있습니다.

## 실행 방법

### 1) 바로 열기
`app/index.html`을 브라우저에서 열면 대부분 동작합니다.
(단, 서비스워커/오프라인 설치 기능은 `file://`에서 비활성화됩니다.)

### 2) 로컬 서버로 열기 (권장 — PWA 설치까지 확인)
```bash
# 저장소 루트에서
npx serve app
# 또는
python3 -m http.server -d app 8080
```
브라우저에서 `http://localhost:8080` 접속 → 모바일에서 "홈 화면에 추가"로 앱처럼 설치 가능.

### 로그인
- **회사 이메일**: `@ii.re.kr` 도메인이면 로그인됩니다 (예: `hong@ii.re.kr`). *목업 인증*입니다.
- **데모 계정으로 둘러보기**: 인증 없이 바로 체험.

> 실제 도메인은 `app/js/store.js`의 `EMAIL_DOMAIN` 상수에서 바꾸면 됩니다.

## 구현된 기능 (MVP)

- 회사 이메일 도메인 인증(목업) · 데모 로그인
- 매물 목록: 검색, 카테고리 필터, 최신순 정렬, 관심/채팅 수 표시
- 매물 상세: 판매자·매너온도, 관심(하트) 토글, 판매중/예약중/거래완료 상태 변경
- 글쓰기: 사진 업로드 미리보기, 카테고리, 판매/나눔/재능교환, 가격, 설명
- 1:1 채팅: 채팅 목록 + 채팅방(간단한 자동응답 목업)
- 마이페이지: 내 판매글·관심 목록·매너온도, 데이터 초기화, 로그아웃
- 라이트/다크 모드(시스템 설정 존중 + 토글 저장), 모바일 반응형, 오프라인 캐시(SW)

## 파일 구조

```
app/
  index.html              # 앱 셸 + 테마 선적용 스크립트
  manifest.webmanifest    # PWA 설치 정보
  sw.js                   # 서비스워커(오프라인 캐시)
  icons/icon.svg          # 앱 아이콘
  css/styles.css          # 전역 스타일(디자인 토큰은 :root 변수)
  js/
    store.js              # localStorage 데이터 계층 + 시드 데이터
    app.js                # 해시 라우터 + 화면 렌더링
```

## 프로토타입의 한계 (실제 서비스로 갈 때 할 일)

이 프로토타입은 "화면과 흐름"을 검증하기 위한 것으로, 아래는 **의도적으로 빠져 있습니다.**

- **서버/DB 없음** — 데이터가 각자 브라우저에만 저장됨(기기 간 공유 X). 실제로는
  백엔드 API + DB로 `store.js`를 교체해야 함.
- **실제 인증 없음** — 이메일 도메인만 확인하는 목업. 사내 SSO 또는 이메일 인증 코드 연동 필요.
- **결제 없음** — 현장 직거래(계좌이체/현금) 전제. 앱 내 결제는 전자금융 규제 검토가 필요.
- **채팅 자동응답은 가짜** — 실시간 채팅은 서버(웹소켓 등)로 구현해야 함.
- **개인정보/보안** — 원내 정보보안·개인정보 담당 부서 승인, 신고/차단·관리자 기능 필요.
