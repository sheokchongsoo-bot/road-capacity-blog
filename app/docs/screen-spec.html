오이마켓
화면 설계서

인천연구원 원내 직원 전용 중고물품·재능 거래 앱 ‘오이마켓’의 화면 구성 문서입니다. 기획·제안서(§3 기능 목록, §4 화면 구성)를 기준으로, 실제 동작하는 프로토타입 화면을 캡처해 구성요소·주요 동작·제안서 매핑을 정리했습니다. 모든 화면 상단에는 인천연구원 코브랜드 바가 항상 노출됩니다.
